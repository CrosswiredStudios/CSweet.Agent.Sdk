# 5.11.0

Add durable delivery correction contracts and a receipt-driven `DeliveryCorrectionCoordinator`. Manager recovery runs before optional incident presentation. Correction planning preserves completed implementation and sprint history, creates a separate repair sprint and validation graph, and keeps original requirements and independent review. Ambiguous ownership, failed preflight and missing grants retain an explicit owned planning wait.

Manager incident reporting has no execution tools and receives bounded evidence. Reporting cannot delegate work or suppress an existing recovery assessment. Runtime/reporting budgets remain within configured ceilings. New workflows order technical review before QA.

Requires Work Management Contracts 5.3.0 and the matching C-Sweet platform migration/correction capability. Publish contracts first, then SDK and dependent agents. Installation through published releases is required; local tests do not deploy changes.
