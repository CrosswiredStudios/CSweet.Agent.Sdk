# 5.21.1

`AgentModelJson.Parse` (and so `ReadAsync`) now reads the first complete JSON object when a provider appends
reasoning markup after it, such as `{...}` followed by `<think>{...}</think>`. Previously the outermost-brace fallback
spanned both and the reply went back for correction. Order of attempts: the whole reply, the first complete object
from the first `{`, then the outermost braces for an object inside prose. Test added.

No API change.
