# SDK 5.8.0

Makes reviewed remote MCP publisher-neutral (protocol 2.6).

- `ReviewedRemoteMcpValidator` no longer pins a plugin id, publisher, endpoint or schemas. It validates structure: an `https` endpoint on port 443 with a public DNS host, `api-key` (`X-` header) or `bearer` (`Authorization`) authentication, `stateless-post` transport, supported MCP revisions, and a closed, read-only, bounded declaration with no other authority. A human approves the endpoint at install review.
- New `reviewedRemoteMcp.tools` maps each provided capability to exactly one remote tool with `effect: "read"`.
- New `ClosedJsonSchema` defines the closed, bounded schema subset used at review (`ValidateDefinition`) and by trusted hosts at dispatch (`Validate`, `IsCompatibleRemoteInput`).
- `ReviewedRemoteMcpValidator.EndpointHost` returns the only DNS host a broker may connect to.
- The manifest JSON schema accepts protocol minimums 2.5 and 2.6 and describes the new declaration.

**Breaking for remote-mcp manifests only:** the 5.7.x closed RealtyLeads profile (protocol 2.5) is rejected with update guidance. RealtyLeadsAI plugin 0.2.0 uses the new form. Agents, services and OAuth connectors are unchanged.

Requires a C-Sweet host with the generic remote MCP broker; older hosts reject protocol 2.6.
