# 5.20.0

An agent that already uses the workspace calls now delivers with git without changing its code.

## What changes for an existing agent

When the platform names a work branch for a prepared workspace (`GitWorkspaceResult.BranchName`) and the runtime can carry Git:

| Call | Before | Now |
|---|---|---|
| `MaterializeAsync` | Downloads a snapshot archive | Clones the repository and checks out the work branch (`CloneAsync`) |
| `UploadAsync`, `UploadCheckpointAsync` | Uploads a snapshot archive | Commits every change, pushes the work branch and records the pushed commit as the checkpoint (`PushCheckpointAsync`). The receipt is the same type |
| `InspectAsync` | Inspects the uploaded snapshot | Names the commit at the local branch head, which the platform inspects |
| `PublishAsync` | Publishes the uploaded snapshot | Names the commit at the local branch head as `PushedCommitSha` |

When the platform names no branch, nothing changes. The mode of a workspace is fixed by what is on disk in the runtime: a workspace downloaded as a snapshot stays a snapshot workspace, and a clone stays a clone.

## Things an agent author should know

- Commits made by `UploadAsync` and `UploadCheckpointAsync` carry the message `chore(wip): save work in progress` and are attributed to the agent's employee identity. They stay on the work branch. `PublishGitWorkspaceRequest.CommitMessage` is unused for a git workspace. Call `CommitAsync` with your own message before uploading if you want a meaningful commit.
- The repository's `.gitignore` is honored, and `node_modules/`, `.venv/` and `.csweet/` are never committed.
- Inspection and publication require the local branch head to be pushed. Upload first, as existing agents already do.
- `RefreshAsync` has no Git behavior yet. The platform does not name a branch for personal work, which uses it.
- `InspectGitWorkspaceRequest.PushedCommitSha` is new; the SDK sets it.

## Compatibility

No manifest change and no new capability name. Requires a platform that inspects, checkpoints and publishes pushed commits; such a platform names a branch only when its operator has turned Git delivery on.

Validation: not yet run. Run the SDK, sample and generated-template tests before publishing. `PlatformGitWorkspaceRemoteTests` runs the real git program.
