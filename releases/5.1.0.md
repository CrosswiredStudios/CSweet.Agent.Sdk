# C-Sweet Agent SDK 5.1.0

Add typed platform research through `PlatformResearchClient.SearchAsync`, `ReadPageAsync`,
and optional `search_web` / `read_web_page` model tools. Research uses the platform's reviewed
SearXNG and protected public-page transport with bounded structured results.

Add private, non-model-visible `PlatformExecutionCheckpointClient` read/write operations for
durable engine sessions, optimistic revision checks, stable mutation keys and separate engine/source
archives. Large archives use bounded, digest-checked chunk transfers. Expose the existing safe
source capture/restore operations for execution adapters.

Synchronize authoring documentation, template defaults, samples and tests to 5.1.0. Depend on
published `CSweet.WorkManagement.Contracts` 5.1.0; existing public work-management contracts are
unchanged by this release. These additive APIs require a C-Sweet host with the corresponding handlers
and reviewed grants.
