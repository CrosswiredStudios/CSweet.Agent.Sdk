# CSweet.Agent.SDK 5.4.1

Shared technical, artifact and aggregate review schemas now require an object at the root. The reflection exporter otherwise permits null for reference-type roots, which structured-output providers reject before reviewing any evidence. Review parsing already rejects a null result, so the schema now expresses the existing contract. Nested nullable fields, evidence bounds, verdict validation, correction limits and retained review checkpoints remain unchanged.

Regression coverage verifies the provider-facing object root and nullable nested fields. This is a compatible maintenance correction. Existing installed agents receive it through a published agent release that updates their SDK dependency; no stored review result is recertified or bypassed.
