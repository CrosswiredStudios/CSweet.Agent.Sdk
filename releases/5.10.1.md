# 5.10.1

Node build readiness runs `npm test --if-present` before the mandatory build and exact-source HTTP check. A repository without a `test` script can provide a valid static scaffold; declared test failures remain fatal. Independent QA and acceptance criteria still apply.

Resume the retained failure from the older mandatory-test recipe only when the exact command, source archive, missing script, completed exit result and restore job are verified. Preserve that failed receipt, observe the existing successful restore job again, then run fresh validation and publication. Unknown outcomes, defined failing tests, changed source and changed commands do not qualify.

Requires matching C-Sweet core validation and an updated readiness executor. Current grants, immutable candidates and generation checks remain mandatory.
