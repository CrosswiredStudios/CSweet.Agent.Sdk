# 5.42.0

The SDK and the companion package `CSweet.Agent.Testing` share delivery routing for personal-work wakes, coordination turns, configuration updates and capability calls. Existing `AgentTestRuntime` callback APIs remain available.

`OperatingStateFixture` registers operating-state reads and writes on a test runtime. Seed a typed payload or a retained checkpoint. The fixture preserves row identity, validates write revisions and replays the original result of an idempotent write across later updates.
