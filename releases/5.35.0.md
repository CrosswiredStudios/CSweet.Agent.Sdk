# 5.35.0

Carry optional exact dependencies from `PersonalTodoResult.WaitingUntil` through the runtime defer command. Matching platform releases reconcile current authorized state on decision writes, defer and reconnect, including decisions made before the wait was saved.

Add `StaffingWorkDescription` and `StaffingReviews` for full work descriptions, named current reporting relationships, current review discovery and dependency references. Resource-change contracts add optional `RevisesRequestId`, distinct from the approved staffing baseline in `SupersedesRequestId`. Models author judgment; code retains identities, capabilities and grants.

Requires Work Management Contracts 5.11.0. Publish contracts, SDK and the matching platform before agents that use these additive fields.
