# 5.15.0

Adds tracked collaborations. `TrackedCollaboration.QueueCardAsync` gives a started chat or board collaboration an owning personal card bound to the exact session and its board; `TrackedCollaboration.ReviewAsync` answers that card's callback from the session's state. A stopped session becomes a typed `CollaborationBlocker`: reason code, owner of the next step, what must change, and whether a retry is useful. All of it is computed in code; no model is asked.

`AgentTestRuntime.AssertCollaborationsTracked()` fails a test when the agent started a chat or board collaboration without an owning card, and `UntrackedCollaborations` lists them. The check is opt-in, so existing agent tests are unaffected. Work-item collaborations are owned by their ticket and are not checked.

Additive. No manifest, protocol or platform change; uses the existing personal to-do and coordination capabilities.

Validation: not built or run by the author of this change. Run the SDK, sample and generated-template tests before publishing.
