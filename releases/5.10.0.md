# 5.10.0

Add `PlatformComputeClient.StageBuildAsync` and `UploadBuildAsync` for exact-source static build archives. Stage installation-owned, hash-checked 64-KiB input parts and submit one resumable compute transfer instead of one agent continuation per upload chunk. Archives are bounded to 16 MiB; repeated staging compares retained bytes before reuse.

Add typed build-input metadata and the optional `ComputeWorkloadResult.BuildArchive` receipt. Callers must verify the receipt's source commit, archive SHA-256 and byte length before browser testing. Existing compute results remain compatible.

Requires matching C-Sweet core and trusted compute-provider support. Operating-state read/write and compute execution remain separately authorized; the API supplies no provider credentials, caller-selected installation identity, public input URL or arbitrary host path. Resumable data transfer does not permit replay of uncertain application commands or browser tests.

Validated with 703 SDK tests, two HelloAgent tests, seven generated-template tests, and package-consumer checks in QA and C-Sweet core.
