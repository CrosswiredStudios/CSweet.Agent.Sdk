# 5.45.0

Decision follow-ups carry a receipt-bound decision, relevant records, permitted document revisions and contacts. The shared dispatcher answers in the employee’s chat turn. When a colleague has the missing fact, it requests clarification through governed coordination and returns the colleague’s response to the originating conversation.

Use the corresponding Headquarters release. Protocol implementations can read the serialized `DecisionInquiryContext` from the existing message event and handle a coordination turn whose source kind is `DecisionInquiry`. Existing installation grants continue to govern document reads and collaboration.
