# SDK 5.8.1

Adds `AgentCatalogSource.ApprovedDefinition` to the unified agent catalog contracts.

- A host lists agent definitions that its owner imported and approved on the Installed Agents page under this source, so every organization on the host can hire them from its marketplace. A hire reuses the approved package; it does not import the repository again.
- Additive only. Manifests, protocol versions, the runtime and the authoring template are unchanged apart from the version pin.

Hosts built against 5.8.0 do not list this source; agents do not consume it.
