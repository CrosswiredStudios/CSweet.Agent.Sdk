# C-Sweet Agent SDK 5.3.0

Add `AgentOperatingStateKey.Create(scope, identity)` to generate a versioned scope plus one full
SHA-256 digest of a structured identity. Keys remain deterministic and within 160 characters
regardless of provider/model name length. Existing valid checkpoint keys remain readable.

`AgentOperatingStateValidation` owns the key character/length contract, request schemas and write
bounds. Typed clients reject invalid requests before dispatch; `AgentTestRuntime` enforces the
same rules for registered operating-state tools, including raw tool calls. The platform consumes
the SDK schemas and validation instead of maintaining separate copies. Fingerprints remain
limited to 128 characters and should use their own digest rather than an arbitrary state key.

Regression coverage includes exact key/payload boundaries, invalid characters, model changes,
stable structured identities, raw test-tool validation and fingerprint overflow. Template and
authoring surfaces now pin SDK 5.3.0. WorkManagement.Contracts remains 5.1.0.
