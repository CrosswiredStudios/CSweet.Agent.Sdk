# 5.9.0

Add accepted imported-project context to organization snapshots, keeping pending profile status separate from owner-accepted project data. Add explicit reviewed project-manager assignment intent to hiring recommendations. Work Management Contracts 5.2.0 supports revision-bound adoption of existing imported projects through normal project setup approval.

Existing snapshots and requests retain their defaults. Imports and profile reads grant no staffing, repository execution or compute authority. Agents must re-read current state after durable wake hints and use stable project-bound idempotency keys.

Validated with 700 SDK tests, the HelloAgent tests, and generation/build/test/self-test of a standalone template repository against versioned packages.
