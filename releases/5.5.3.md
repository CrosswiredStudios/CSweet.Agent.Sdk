# CSweet.Agent.SDK 5.5.3

- Suppress routine Information logs only for the private runtime HTTP client. Frequent successful broker calls can otherwise exhaust the isolated guest lifetime log budget and terminate long-running QA.
- Preserve runtime warnings, errors and work-failure diagnostics. Application and unrelated HTTP logging remain unchanged; explicit later filters can enable bounded transport tracing.
- No public API, grant, isolation or log-budget changes.
