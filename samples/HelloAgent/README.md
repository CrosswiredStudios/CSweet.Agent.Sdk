# HelloAgent

A complete minimal C-Sweet agent package that implements `hello.say.v1`. It requests no platform
capabilities, subscribes to no events, and has no network access.

```powershell
dotnet test
dotnet run --project src/HelloAgent -- --self-test
```

The sample uses a source `ProjectReference` because it is maintained inside the SDK repository.
Agents generated by `dotnet new csweet-agent` use the pinned `CSweet.Agent.SDK` NuGet package.
