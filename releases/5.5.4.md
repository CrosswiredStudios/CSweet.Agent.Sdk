# CSweet.Agent.SDK 5.5.4

Work-claim HTTP deadlines now include the requested long-poll interval plus the control-response budget. Late claims can return before the caller abandons them and leaves an unrenewed work lease.

Other control deadlines and work leases remain bounded and unchanged. Caller cancellation is preserved; unknown claim outcomes are not replayed. Regression tests cover delayed replies, timeout bounds, cancellation and poll clamping.
