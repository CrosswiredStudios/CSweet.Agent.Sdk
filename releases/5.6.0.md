# SDK 5.6.0

Adds a closed, reviewed remote-MCP manifest profile for the RealtyLeadsAI read-only provider. The trusted host owns API-key entry, encrypted account storage, grants and transport; agent callbacks receive only typed business capabilities. This profile requires a compatible protocol 2.5 host and cannot be imported by older hosts or used as an OAuth connector.

Includes the 5.5.3 runtime HTTP log-budget fix and the 5.5.4 bounded long-poll claim deadline fix. Existing OAuth connector validation remains unchanged.
