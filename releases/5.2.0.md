# C-Sweet Agent SDK 5.2.0

`InspectGitWorkspaceRequest` can opt into bounded assignment history with `IncludeHistory`, `HistoryOffset` and `HistoryLimit`. `GitWorkspaceInspection.History` returns typed source/publication identities, parent commits, subjects, paging and current default-branch ancestry. Existing inspection callers remain compatible.

The existing inspection capability remains read-only and assignment-scoped. Repository, source commit, publication and default ref are chosen by Core, not the caller. No credentials, transport, push or history-rewrite API is exposed. Deploy the matching platform before enabling history readers. WorkManagement.Contracts remains 5.1.0.
